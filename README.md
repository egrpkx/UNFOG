# UNFOG · Android prototype 0.1

Нативный Android GPS-трекер с исследованием города через туман войны.

## Реализовано в исходниках
- Полноэкранная светлая векторная карта MapLibre + OpenFreeMap Positron.
- Графитовый туман войны; открываемый радиус 40 м, 4 слоя для мягкой границы, анимация появления.
- Туман открывается **только при активной записи** поездки; при паузе координаты не записываются.
- Фоновая запись GPS через foreground location service с системным уведомлением.
- Текущая / средняя скорость, дистанция, время, старт, пауза, продолжить, завершить.
- Локальная SQLite-база (поездки и координаты) с историей и предварительным просмотром маршрута.
- Фильтрация неточных GPS-фиксаций, невозможной скорости и мелких смещений.

## Как запустить
1. Установите **Android Studio** с SDK Platform 35, Build Tools и JDK 17.
2. Откройте **корневую папку проекта** (где `settings.gradle.kts`).
3. Если Android Studio просит Gradle, выберите Gradle 8.9; проект **не содержит официальные бинарники Gradle Wrapper**.
   Можно в терминале с установленным Gradle выполнить `gradle wrapper --gradle-version 8.9`, затем `./gradlew assembleDebug`.
4. Дождитесь синхронизации проекта с Maven / Google repositories (нужен интернет).
5. Подключите Android-телефон, включите GPS и установите приложение кнопкой Run.
6. Для получения APK: `Build > Build APK(s)`; файл будет `app/build/outputs/apk/debug/app-debug.apk`.

Минимальная версия: Android 8.0 (API 26). Карте требуется интернет. Для надёжного GPS-тестирования желательно выйти на улицу.

## Что в прототип **не** входит
- Регистрация, сервер и облачная синхронизация. Пока данные хранятся **только на телефоне**. При удалении приложения данные будут удалены.
- Полноценные офлайн-карты, экспорт GPX, статистические графики, защита от всех энергосберегающих ограничений производителей.
- Подписанный релизный APK и готовая проверенная сборка — сборка не выполнялась в среде создания этих исходников.

## Технические замечания
- Фоновая запись начинается только после пользовательского нажатия «Начать»/«Продолжить».
- В Android 14+ разрешение на foreground service типа `location` уже указано в манифесте.
- Функция `TripDatabase.recordLocation()` определяет, какие GPS-фиксации сохраняются и открывают туман.
- `FogOverlay` проецирует сохранённые GPS-точки при любом масштабе, чтобы открытие оставалось привязанным к реальному местоположению, а не к пикселям экрана.
- Тайлы и права их использования: https://openfreemap.org/ и https://www.openstreetmap.org/copyright

## Сборка APK без Android Studio (через GitHub Actions)

В проект включён `.github/workflows/build-android.yml`.

1. Создайте пустой репозиторий GitHub и добавьте содержимое этой папки (не сам ZIP-архив).
2. Откройте вкладку Actions → Build Android APK → Run workflow.
3. Дождитесь окончания сборки. Внизу страницы запуска появится артефакт `Unfog-debug-APK`.
4. Скачайте артефакт, распакуйте его — внутри будет `app-debug.apk`.

Это **debug APK** для личного тестирования, не публикация в Play Store. Workflow включён как инструкция для внешнего сборочного окружения; его запуск и успешность здесь не проверялись.
