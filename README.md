# UNFOG 0.5.0 — полный проект Android

**Это единый ПОЛНЫЙ архив исходников.** Он заменяет предыдущие архивы UNFOG 0.2, 0.3 и 0.4; ничего из них дополнительно копировать не нужно. Это НЕ готовый APK.

## Что есть в этой версии

- Карта OpenFreeMap на MapLibre, GPS-позиционирование.
- Начать / пауза / продолжить / завершить поездку. Только во время активной записи открывается туман.
- Текущая GPS-скорость с расчётной подстраховкой, средняя скорость, длительность и дистанция.
- Фоновая запись поездки через Android foreground service (постоянное уведомление).
- Более частые GPS-запросы (около 1 секунды; реальная частота зависит от Android/устройства/сигнала), фильтрация ошибок и запрет вымышленных прямых через длинные GPS-пробелы.
- Треугольный туман войны со стабильной географической сеткой; ранее открытые участки остаются открытыми.
- История поездок, выделение маршрута целиком, точки старта и финиша, удаление с подтверждением.
- Явная кнопка **«Настройки» с шестерёнкой**, которая открывает «Исследование территорий» и показывает версию `UNFOG 0.5.0`.
- Выбор города, региона или страны по поиску через OpenStreetMap/Nominatim (нужен интернет); расчёт приблизительного процента исследованной площади по треугольникам. Смена территории не удаляет маршруты.
- Локальная SQLite-база на устройстве. **Облачной регистрации, синхронизации и резервного копирования пока нет.**

## Как загрузить в существующий репозиторий GitHub

1. **Не загружайте сам ZIP как единственный файл** — распакуйте его на компьютере.
2. Откройте в GitHub репозиторий UNFOG → вкладка Code → `Add file` → `Upload files`.
3. Перетащите **содержимое** распакованной папки в окно загрузки (не родительскую папку), **сохраняя пути и подпапки**: `app`, `.github`, `gradle` и файлы корня. Если GitHub не позволяет корректно загружать папки, воспользуйтесь GitHub Desktop или локальным git push. Скрытая `.github` должна попасть в репозиторий.
4. В GitHub проверьте, что появились/заменились именно пути `app/src/main/res/layout/activity_main.xml`, `app/src/main/java/com/unfog/app/ui/MainActivity.kt`, `app/src/main/res/drawable/ic_settings.xml`, а также `.github/workflows/build-android.yml`.
5. Нажмите `Commit changes`. Перейдите в Actions → Build Android APK. Сборка должна запуститься после коммита; если нет, вручную нажмите Run workflow.
6. После **зелёной** сборки откройте её страницу, прокрутите до `Artifacts`, скачайте `Unfog-debug-APK` и извлеките `app-debug.apk`.
7. Установите APK на телефон и проверьте, что наверху теперь есть кнопка «Настройки», а в диалоге указано `UNFOG 0.5.0`.

## Как убедиться, что загрузился именно новый проект

- В файле `app/build.gradle.kts` должно быть `versionCode = 5`, `versionName = "0.5.0"`.
- В `app/src/main/res/layout/activity_main.xml` должна быть строка `android:text="Настройки"` у `territoryButton`.
- Кнопка «Настройки» должна появиться на главном экране, а окно настроек показывать версию `0.5.0`.

## Важно о сохранности данных

Не удаляйте прежнее приложение, если важны локальные поездки. Android может не позволить установить debug APK поверх старой сборки, потому что GitHub Actions использует новый debug-ключ при каждой сборке. Удаление установленного приложения уничтожит его локальные данные. `applicationId` не менялся (`com.unfog.app`), структура SQLite не менялась, но обновление поверх старой сборки всё равно зависит от подписи.

## Ограничения

* Процент территории — игровой, приблизительный: треугольная сетка (90 проекционных метров сторона) и открытие вокруг маршрута радиусом примерно 40 реальных метров.
* Точность трека и скорость зависят от качества GPS, особенностей телефона и разрешений Android.
* Публичный Nominatim ограничивает обращения; поиск запускается вручную и не подходит для массовой нагрузки.
* Для отображения базовой карты необходим интернет.
* Компиляция в Android SDK и проверка на физическом устройстве в этой среде **не выполнены**. Зеленая сборка в GitHub Actions нужна для подтверждения работоспособности APK.

## Технологии

Kotlin 2.2.10 · Android Gradle Plugin 8.10.0 · Gradle 8.11.1 · MapLibre 13.6.1 · SQLite · OpenFreeMap + OSM Nominatim.
